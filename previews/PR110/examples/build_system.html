Build a regional system ​

This page builds a PowerSystems.jl System of the NEM's five regions from cached NEMWEB data. For the market itself (its regions, dispatch process and prices), see The National Electricity Market.

Simple usage ​

This package handles the download of data from the NEMWEB Archive and the parsing of the data into a System from PowerSystems.jl. RegionalNetworkConfiguration builds a zonal model in which each region is a single node, for economic dispatch studies. NEMDEConfiguration builds the full NEMDE system, with bids, FCAS, constraints and losses, used to run NEMDE dispatch. By default, the package will create a hidden folder .nemdb_cache in the home directory, and save the data into parquet files.

julia
using AustralianElectricityMarkets
using AustralianElectricityMarketsData: populate
using Dates
using DuckDB
using PowerSystems
using DataFrames
using Chain
using CairoMakie, AlgebraOfGraphics

db = aem_connect();
date_range = Date(2025, 1, 20):Date(2025, 1, 31)
Dates.Date("2025-01-20"):Dates.Day(1):Dates.Date("2025-01-31")

populate( db, first(date_range), last(date_range); tables = table_requirements(RegionalNetworkConfiguration()), )

Once the data is downloaded, a few utility functions allow direct parsing of key quantities, such as a table of all units registered in the NEM, or the region zonal operational demand.

julia
units = read_units(db, date_range)

capacity_by_fuel = @chain units begin
    select(:DUID, :REGISTEREDCAPACITY, :CO2E_ENERGY_SOURCE, :REGIONID)
    groupby([:CO2E_ENERGY_SOURCE, :REGIONID])
    combine(:REGISTEREDCAPACITY => (x -> sum(x) / 1000) => :installed_capacity_gw)
    dropmissing
    sort!(:installed_capacity_gw)
    subset!(:installed_capacity_gw => ByRow(>=(0.1))) ## Ignore marginal sources
end

spec = mapping(
    :REGIONID,
    :installed_capacity_gw => "Installed capacity [GW]",
    stack = :CO2E_ENERGY_SOURCE,
    color = :CO2E_ENERGY_SOURCE => "Fuel source"
) * visual(BarPlot, alpha = 0.8)
fig = data(capacity_by_fuel) * spec
draw(
    fig,
    figure = (; title = "Installed capacity in the National Electricity Market by energy source"),
    scales(Color = (; palette = from_continuous(:Paired_12)))
)

Read the demand for each state. In the NEM, this is referred to as Operational Demand, which is the demand met by local scheduled and semi-scheduled generation, plus net imports from other regions. It excludes "behind-the-meter" rooftop PV, which instead appears as a reduction in operational demand.

julia
demand = read_demand(db, date_range)

begin
    spec = data(
        subset(demand, :SETTLEMENTDATE => ByRow(x -> (Date(2025, 1, 20) <= x <= Date(2025, 1, 31))))
    )
    spec *= mapping(:SETTLEMENTDATE => "Date", :TOTALDEMAND => "Total Demand [MW]", color = :REGIONID => "State")
    spec *= visual(Lines)
    figure_options = (;
        title = "Regional demand in each Australian state",
        subtitle = "Period of January 20th 2025 to January 31st 2025",
    )
    draw(spec; figure = figure_options)
end

Australia has a fairly high penetration of PV, which at times exceed a state's total demand for electricity (in SA in particular). read_demand does not return the semi-scheduled solar availability, so it is queried from DISPATCHREGIONSUM directly.

julia
source = read_hive(db, :DISPATCHREGIONSUM)
solar = DataFrame(
    DuckDB.execute(
        db.db,
        """
        SELECT SETTLEMENTDATE, REGIONID, SS_SOLAR_AVAILABILITY
        FROM $source
        WHERE SETTLEMENTDATE >= '2025-01-20' AND SETTLEMENTDATE <= '2025-01-31'
          AND SS_SOLAR_AVAILABILITY IS NOT NULL
        """,
    ),
)

begin
    spec = data(
        subset(solar, :SETTLEMENTDATE => ByRow(x -> (Date(2025, 1, 20) <= x <= Date(2025, 1, 31))))
    )
    spec *= mapping(:SETTLEMENTDATE => "Date", :SS_SOLAR_AVAILABILITY => "Semi-scheduled solar availability [MW]", color = :REGIONID => "State")
    spec *= visual(Lines)
    figure_options = (;
        title = "Solar generation from semi-scheduled units per state",
        subtitle = "Period of January 20th  2025 to January 31st 2025",
    )
    draw(spec; figure = figure_options)
end
