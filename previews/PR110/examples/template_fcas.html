FCAS markets ​

This page runs the intervals of Running NEMDE dispatch with the same run interface. Only the preset-specific parts are new here.

The preset is the interconnector-loss run with the FCAS market added. NEMDE models the FCAS requirements as generic constraints, so the preset keeps those (constraints = :fcas_requirements) and leaves out the other generic constraints. The preset has no tie-break. It corresponds to nempy's FCAS example.

The template and the decision model ​

The presets are run with fast_start = false, because fast start is an option of the sequence.

julia
template = template_fcas();
(; models, sequence) = nem_dispatch_sequence(
    NEMDispatchProblem, template, sys;
    fast_start = false, optimizer = nemde_optimizer(; output_flag = false), initial_time = first(steps),
);

Compare with NEMDE ​

The FCAS prices are the regional prices of each bid type, compared with the published regional original prices (ROP). The table shows the first interval; the summary covers all three.

julia
results = PSI.get_decision_problem_results(PSI.SimulationResults(simulation), "dispatch");
solved = read_solved_interval(results, sys);
comparison = compare_intervals(read_published_interval(db, steps), solved);

@chain comparison.fcas_prices begin
    subset(:SETTLEMENTDATE => ByRow(==(first(steps))))
    select(:REGIONID, :BIDTYPE, :ROP_published, :ROP_solved)
end
